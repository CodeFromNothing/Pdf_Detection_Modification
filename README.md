# CIN PDF Modifier

Simple Python project that detects the CIN number in a PDF and replaces it with a modified value.

## Features

* Detect the CIN number from the PDF
* Replace the detected value
* Generate a new modified PDF

## Run

```bash
python Project_Id.py input.pdf
```

The modified PDF is generated as a new file.

> Intended for testing and anonymization of sample documents, not for altering official identity documents.
